Моя геройская академия: В поле зрения

Играть в браузере: https://safeniy.github.io/My-hero-academy-fan-hame/
Установка не нужна. Если видна старая версия, обновите страницу с очисткой кэша.

Обновление: прозрачные портреты 22 персонажей, сохранённые эмоции,
восстановленные плечи и одежда, общий масштаб и отдельные миниатюры.

Для своего HTTPS-сайта распакуйте ZIP и разместите содержимое папки
с index.html на статическом хостинге. Поддерживается подкаталог.
Для локального запуска откройте терминал в распакованной папке,
выполните python -m http.server 8000 и откройте http://localhost:8000/.
Прямое открытие index.html через file:// может блокировать загрузку ресурсов.

Сохранения хранятся в браузере и привязаны к адресу сайта.
Перед очисткой данных или переездом экспортируйте их в меню сохранений.

Это неофициальная фанатская игра. Атрибуция и лицензии — в меню игры.
Тяжёлые оригинальные PNG и RAR в сборку не включены.
