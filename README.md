# В поле зрения — сборка браузерной новеллы

Эта ветка содержит ZIP готового статического сайта. Архив: v-pole-zreniya-web.zip (3,24 МиБ).

Восемь глав, двадцать личных маршрутов и дружеская ветка, сохранения, локальная музыка. Пользовательские спрайты ещё не подключены: исходный архив не удалось передать в среду из-за лимита 32 МиБ. Вместо них используются временные символы. Неофициальный фанатский проект.

Для скачивания откройте файл v-pole-zreniya-web.zip и нажмите Download raw file. Разместите содержимое ZIP на HTTPS-хостинге. Это сборка сайта, не установленный сайт. Открытие index.html через file:// не поддерживается.

Сохранения хранятся в браузере; резервная копия — через экспорт в меню игры. Авторы и лицензии — внутри игры и ZIP. Ветка предназначена для передачи проверенной сборки; основная ветка и исходные рабочие файлы не заменены.
